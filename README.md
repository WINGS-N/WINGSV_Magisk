# WINGS V root helper (`wingsvd`)

Опциональный модуль для [WINGS V](https://github.com/WINGS-N/WINGSV). Совместим с
Magisk, KernelSU Next и APatch.

**Приложение работает и без него.** Модуль ничего не добавляет к возможностям — он
меняет то, кому принадлежит маршрутизация.

## Зачем

Правила маршрутизации живут в ядре, а ставит их приложение, которое Android волен убить
в любой момент. Если это происходит посреди разбора туннеля, правила переживают туннель
и уводят весь трафик в мёртвую таблицу — телефон остаётся без интернета. Особенно легко
поймать это при отключении через плитку в шторке: приложение не на экране, и держать его
живым некому.

Демон запускается через init и не подчиняется правилам жизненного цикла Android: ни
контракта foreground-сервиса, ни low-memory killer, ни ограничений фонового старта.

Побочно это делает поведение лучше, чем без модуля: если приложение убили, туннель
**остаётся жить** (сессия помечается осиротевшей), а не рвётся — убийство приложения
почти всегда LMK, а не намерение пользователя. Погасить её можно из плитки или вернувшись
в приложение.

## Безопасность

- сокет в abstract namespace: дотянуться может любой процесс, поэтому каждое соединение
  проверяется по `SO_PEERCRED` — uid подставляет ядро, подделать его нельзя;
- uid приложения читается из базы пакетов на каждое соединение (он меняется при
  переустановке; закешированный однажды uid мог бы отдать root чужому пакету);
- демон никогда не исполняет присланную строку: маршрутизация собирается из
  типизированной спеки, а запускать можно только бинарники из `nativeLibraryDir`
  приложения.

## Сборка

```
./build-module.sh          # -> dist/wingsv-root-module.zip
```

Нужны `cargo-ndk`, таргеты `aarch64-linux-android` и `armv7-linux-androideabi`, и NDK
(`ANDROID_NDK_HOME`).

Готовый zip также прикладывается к каждому релизу WINGS V.

## Протокол

`proto/rootd.proto` — единственный источник истины: демон генерирует из него Rust через
prost, а приложение симлинкает файл к себе и генерирует Java. Версия сверяется при
`Hello`; при рассинхроне приложение **не** использует демона, откатывается на su и один
раз показывает уведомление.
